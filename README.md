# 崩壊スターレイル 編成くらべ

個人が作った**非公式のファンメイドツール**です。HoYoverse や公式とは関係ありません。
編成を並べて DPA（行動値あたりダメージ）を比べます。

<https://maom-code.github.io/hsr-sim-web/>

- 計算はすべて**閲覧者のブラウザの中**で走ります（サーバーに何も送りません）
- 数値は自作シミュレータの計算値で、実機と一致するとは限りません。
  前提はページ内の「この計算でやっていないこと」に書いてあります
- キャラクターのアイコンは [StarRailRes](https://github.com/Mar-7th/StarRailRes) のものです。
  ゲーム内の名称・画像は HoYoverse に帰属します
- 間違いを見つけたら [@houryu_ji](https://x.com/houryu_ji) まで

このリポジトリは**書き出し済みのファイルを置いているだけ**です（`index.html` /
`worker.js` / `hsr-bundle.zip`）。
